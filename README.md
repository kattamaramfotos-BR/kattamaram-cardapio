# Kattamaram II — Cardápio + Painel

1. Edite `supabase-config.js` com a Project URL e a chave pública anon/publishable do Supabase.
2. Envie os arquivos para o repositório do GitHub.
3. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
4. Cardápio público: `index.html`.
5. Painel: `admin.html`.

Nunca coloque a service_role key no frontend.
